- macOS: an app that places its traffic lights (`Chrome::traffic_lights`) no longer aborts on launch on macOS 26, or crashes later when AppKit removes an observer from its titlebar (#873). Rune gave the titlebar container and the buttons' superview a per-instance subclass; when AppKit already observed one with KVO, Rune's class landed above KVO's, so AppKit's observer read no value and a Swift cast to `NSTitlebarContainerView` failed. The `-layout` hook now sits on each view's own AppKit class, under any KVO subclass, so the buttons stay at the app's spot and KVO's class stays on top.
